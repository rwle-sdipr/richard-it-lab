# Git & GitHub Notes

This folder contains my notes and exercises while learning Git and GitHub.

## Key Concepts

### Repository
A repository stores a project and its version history.

### Commit
A commit records a snapshot of changes made to the repository.

### Branch
A branch provides a separate line of development where changes can be made without immediately changing the main branch.

### Pull Request
A pull request proposes changes from one branch to another so they can be reviewed before merging.

### Merge
A merge combines changes from one branch into another.

## Workflow I'm Learning

1. Start from the main branch
2. Create a feature branch
3. Make changes
4. Commit the changes
5. Create a pull request
6. Review the changes
7. Merge into main
